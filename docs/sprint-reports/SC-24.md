## State truth and URL migration

`scene_id` is separate from camera, selection, scale, context, layers, and preserved length. A
scene remains pressed only when its complete meaningful state matches its declarative record.
Manual orbit, raw camera selection, ring-count changes, and detail-layer changes therefore produce
Custom unless the resulting complete state exactly matches a named scene. Custom context survives
URL/history restoration so its relevant contextual controls remain available.

Canonical scene example:

```text
#v=2&depth=learn&step=meet_sarcomere&sl=2200&drawer=closed&scene=overview&confidence=0
```

Canonical Custom example, shown decoded for readability (the actual hash percent-encodes commas):

```text
#v=2&depth=learn&step=meet_sarcomere&sl=2200&drawer=closed&camera=closeup.lattice&scale=context&target=none&context=1&layers=extended_lattice,lattice_rings_2,show_context_detail,show_lattice&confidence=0
```

The serializer emits either `scene` or the complete Custom representation, never both. Layer keys
are sorted. A mixed scene plus conflicting Custom state is visibly restored as Custom. Intentional
Custom state remains Custom even if its serializable fields happen to equal a scene, because a
manual orbit can change the actual camera transform without changing the stable camera-preset key.

`confidence` is a top-level field beside `depth` and `drawer`, not part of the Custom bundle,
because the evidence-opacity reading preference says nothing about which biology is on stage.
Explore therefore keeps truthful semantic-scene state: `depth=explore&scene=lattice&confidence=1`
is canonical, and the seven scene buttons report what is actually shown in both depths.

Scale/context contradictions, close-ups missing the filament lattice they are framed against, and
M-line views missing their mirror are repaired with a visible shared-state notice; serialization
refuses to emit such impossible states. The myosin-head/actin-twist layer is deliberately not one
of them: it is a reviewed scene default that its primary control can turn off, so a shared link has
to be able to carry it either way. Fresh Custom restoration uses the same inference path as history
restore, so contextual controls and source filtering remain available.

V1 migration is deterministic:

| V1 intent | V2 result |
| --- | --- |
| `mode=guided` | `depth=learn`, `drawer=closed` |
| `mode=evidence` | `depth=explore`, `drawer=inspect` |
| Chapter alias | Canonical v2 chapter ID |
| `sl`, camera, target, scale, evidence display | Preserved in scene or complete Custom state |
| Value with no exact v2 equivalent | Safe fallback plus a non-blocking shared-state notice |

Exact migrations are silent. The Story visible/hidden preference is deliberately absent from URLs;
it persists only in current-tab `sessionStorage`, survives reload and rotation, and starts visible in
a fresh browser session. Hide returns focus to Story; reopen returns focus to the unchanged chapter
heading. Escape dismisses More, then a pinned object, then the drawer, then Story.

## Stretch behavior

Stretch routes through the normal Spring scene action whenever the starting view is a chapter
camera, close-up, or otherwise cannot carry the full half-sarcomere. It announces the transition,
frames once against 2,400 nm before the first length frame, and biases the camera into the vertical
band not occupied by the header, Story, or primary bar. The full projected route and canonical band
endpoints remain within that unobscured band at the start and supported maximum.

The I-band bracket is a required Spring feature even when the starting chapter normally omits band
brackets, and it survives any Custom state reached from Spring. “Watch the I-band
bracket” remains visible while running. Slow/software-rendered frames
cap their visual time step so the demonstration cannot skip from start to finish without showing
the changing state. Pause freezes the current length, Reset restores the exact start through the
normal Spring action, and leaving Spring invalidates Reset so a stale demonstration cannot overwrite
another scene. Reduced motion lands directly on the same Spring maximum without a tween.

## Post-review corrections

An independent audit after the first handoff reproduced every automated gate and then found
behaviour the gates could not see. Each item below now has a regression that was watched failing
against the pre-fix build.

| Defect | Symptom | Correction |
| --- | --- | --- |
| Close-up cameras required the context-detail layer at runtime | The contract's own “Myosin heads + actin twist” control threw on its first click from Lattice, Architecture, and A-band scaffold, painting the full-stage error panel; the same crash reached the mobile sheet and both Explore drawer switches | The requirement is a scene-record default, not a camera invariant; runtime serialization and URL repair now require only the filament lattice |
| Confidence display erased scene truth | Every semantic scene read Custom throughout Explore | `confidence` promoted to a top-level URL field |
| Manual-camera detection fired on pointer-down | An ordinary click that moved nothing announced “Camera adjusted manually” and replaced a shareable `scene=` link | The gesture is bracketed; the announcement waits for a real camera change between `start` and `end` |
| Camera re-application re-forced the detail layer | A restored Custom link silently switched the layer back on and rewrote the shared hash | Only genuine close-up invariants are re-applied |
| No browser spec asserted the runtime-error channel | A fatal module error passed the whole suite unnoticed | `failOnPageErrors` is a standing `beforeEach`/`afterEach` gate on both SC-24 specs, and the control regressions also assert `#err` mid-test |
| Desktop duplicated its contextual controls; the phone had no scene-truth readout | Redundant primary-bar action on desktop, no visible Custom signal at 375 px | Scene details is a phone-only route; the readout keeps a collapsible column on the phone bar |

The stage shortcut legend, which is the canvas's accessible description, now names Spring, Explore
and Learn instead of the retired extension/evidence/guided wording.
