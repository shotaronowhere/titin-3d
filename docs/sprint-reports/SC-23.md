## State, accessibility, and negative controls

- Chapter navigation changes camera, scale, visibility, and selection, announces that change, and
  preserves the current sarcomere length. It also enables a one-step `Restore previous view` action
  that restores framing, layers, and selection without changing the current chapter or length. A
  current length inside 2,000–2,400 nm starts the bounded sweep from that exact value.
- An outside-range value cannot start silently. `Set demonstration start` records the prior value,
  moves to the declared lower bound, and enables `Restore previous length`.
- Previous/Next controls name their destination and the chapter map reports “Chapter n of 7.” The
  final scene returns to `view.titin_story` with complete titin selected and offers Replay stretch,
  Inspect a region, and Open evidence.

  Python validators reject undeclared fields, every numeric leaf, evidence-class values, scientific
  key names, duplicate claims, malformed nested shapes, scene drift, and unresolved references.
